# Fizz Bomb

A shake-your-phone game. Shake to build CO₂ pressure in a soda bottle, then pop the cap for the tallest geyser you can get. Go past the bottle's pressure limit and it bursts.

- Open `index.html` on a phone over HTTPS (for example via GitHub Pages) so the motion sensor works. iPhone asks for motion permission when you tap **Start**.
- On a computer, grab the bottle and shake it with the mouse.
